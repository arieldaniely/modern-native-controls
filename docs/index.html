קטן בקוד, גדול בחוויה

כל מה שצריך. שום דבר שלא.

רשימות שבאמת נראות טוב

גם השדה הסגור וגם תפריט האפשרויות מקבלים מראה קומפקטי, גלילה נעימה ואנימציה עדינה.

לוח עברי ולועזי

מעבר חלק בין הלוחות, חיפוש תאריך עברי והמרה אוטומטית לערך ISO לועזי עבור הטופס.

כהה, בהיר וצבעי המותג

התוסף מזהה את צבעי האתר ומתאים אליהם משטחים, טקסט, גבולות וצבע הדגשה.

בנוי לביצועים

ללא שרת, ללא ספריות כבדות וללא בקשות רשת. רק CSS ו־JavaScript ממוקדים.

מכבד עיצוב קיים

רכיבים שכבר עוצבו בידי האתר שומרים על המעטפת שלהם; רק ממשקי המערכת המיושנים מוחלפים.

פרטי לחלוטין

אין איסוף נתונים, אין analytics ואין הרשאות API מיותרות. העיצוב מתבצע מקומית בדפדפן.

התקנה בפחות מדקה

ארבעה צעדים.
וכל האינטרנט נראה טוב יותר.
