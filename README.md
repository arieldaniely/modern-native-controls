# Modern Native Controls

[דף הבית והדגמה חיה](https://arieldaniely.github.io/modern-native-controls/) · [הורדת הגרסה האחרונה](https://github.com/arieldaniely/modern-native-controls/releases/latest)

## תאימות לעיצוב האתר

רכיב שכבר כולל `class` או `style` שומר על העיצוב החיצוני של האתר. התוסף מחליף רק את תת־הרכיב הפנימי שנפתח — תפריט האפשרויות או לוח השנה. כדי להשאיר רכיב שלם ללא התערבות, יש להוסיף לו או לאחד מאבותיו `data-mnc-ignore`.

תוסף Chrome זעיר שמעניק לרכיבי טפסים מקוריים מראה מודרני ועקבי.
ב-Chrome 135 ומעלה גם החלון שנפתח מתוך `select` מעוצב במלואו.

## התקנה

1. חלץ את קובץ ה-ZIP לתיקייה קבועה.
2. פתח ב-Chrome את `chrome://extensions`.
3. הפעל **מצב פיתוח**.
4. לחץ **טעינת פריט שלא נארז** ובחר בתיקייה `modern-native-controls`.

כדי לבדוק את התוסף על קובץ HTML מקומי, פתח את פרטי התוסף והפעל
**אפשר גישה לכתובות URL של קבצים**.

## מה כלול

- `select` רגיל ורשימת בחירה מרובה
- בחירה מרובה מותאמת עם סימוני checkbox, Shift לבחירת טווח ומקלדת
- `input[type=date]` עם אייקון יחיד וללא שכפול של רכיב המערכת
- לוח שנה קומפקטי עם מעבר ישיר בין חודשים ושנים
- מתג תצוגה לועזי/עברי מלא
- חיפוש תאריך לועזי או עברי, למשל `י״ח באב תשפ״ו`
- תאריך עברי נשלח לטופס כערך ISO לועזי תקני
- ניווט מקלדת, היום וניקוי
- checkbox ו-radio
- בחירת קובץ (`input[type=file]`) ובחירת צבע (`input[type=color]`)
- `button` וכפתורי input
- פסי גלילה צפים שאינם תופסים מקום ונעלמים כשאין גלילה; פס גלילה שהאתר כבר עיצב נשאר ללא שינוי
- מצבי hover, focus, checked ו-disabled
- RTL, מצב כהה ובהיר והעדפת reduced-motion
- התאמת צבעים אוטומטית לרקע, לטקסט ולצבע המותג של האתר
- מעבר מונפש ונגיש בין הלוח הלועזי לעברי

## ביטול עיצוב באזור מסוים

כדי להשאיר רכיב או אזור שלם בדיוק בעיצוב המקורי של האתר, מוסיפים
`data-mnc-ignore` לרכיב או לאחד מאבותיו:

```html
<form data-mnc-ignore>
  <!-- התוסף לא משנה דבר בתוך הטופס הזה -->
</form>
```

התוסף אינו אוסף או שולח מידע ואינו מבקש הרשאות API נוספות. הגישה לדפי האינטרנט
נדרשת רק כדי להחיל עליהם את העיצוב. קוד JavaScript קטן ומבודד
מספק לוח שנה מעוצב, מסונכרן ונגיש במקום החלון של מערכת ההפעלה.
מנגנון ה-picker החדש של Chrome אינו תומך כרגע ב-`select multiple`.
לכן התוסף מספק לרשימה מרובה רכיב מותאם משלו, שמסנכרן את הבחירות עם
ה-`select` המקורי ועם הטופס.
